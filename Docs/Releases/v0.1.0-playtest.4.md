The Howl now arrives as eight distinct creatures, with different silhouettes, movement and regional appearances. This update includes all twelve faction themes, 76 defenders and the construction performance improvements from Playtest 3.

## New in Playtest 4

- **Eight recognizable enemy forms:** Hearthgnawer scavengers, thorn-maned Thornrunners, six-legged Ashling swarms, tusked Cairnbacks, antlered Hollow Wardens, Gloamwing moths, ram-headed Gatebreakers and the final wave's Storm Heralds.
- **Regional character:** earthy soot, ochre and bone on Ironfold; pale stone, blue-grey coats and frost details on Rimewatch.
- **Living movement:** distinct gaits and wing motion, hit recoil, attack twists and a visible slow-effect ring. Animations follow game speed and pause.
- **Clearer inspection:** enemy names appear in Details. Ground creatures fit their existing collision footprint; decorative anatomy adds no blockers.
- Shared, warmed model assets keep pose updates allocation-free in the measured checks. Existing wave counts, enemy stats, rewards, map routes, faction balance and network protocol are unchanged.

![The eight Ironfold creatures, magnified in the Unity roster gallery](https://raw.githubusercontent.com/AdamGardelov/howl-for-maul/f18ce85ab18e7615e8463991794a68999a58b0ce/Docs/Verification/Howl-Host/Roster-Ironfold-Roster.png)

This is a first creature presentation pass, not new enemy abilities or a new boss encounter. Species-specific vocals and death animation remain future work.

## Play together

**Everyone should install Playtest 4 into a fresh folder and use the same version.** Choose **Play → map → Multiplayer → Host online**, then share the join code and optional password privately. Friends choose **Join with code**. Relay does not require router port forwarding. Choose factions and starts, vote difficulty, and defend together.

Enter opens team chat; P votes to pause/resume; the host controls speed. Keep the host's game open: reconnect and host migration are not available. Solo works offline and starts at Last Stand with the full team budget.

## Verification and playtest limits

75 headless simulation regressions and 82 targeted Unity cases pass across two final runs, including both historical paid twenty-wave Hard campaigns, paid construction during waves, creature footprints, pause/recoil and world/audio integration. Linux packaged runtime, creature renders, menu/resize and both-map local two-process multiplayer checks pass. [Implementation and evidence](https://github.com/AdamGardelov/howl-for-maul/blob/f18ce85ab18e7615e8463991794a68999a58b0ce/Docs/HOWL-HOST.md).

This remains a **free prerelease**. Windows cross-build succeeds, but native Windows execution is unverified here and the executable is unsigned. Rendering checks used Linux software OpenGL, not target gaming hardware. Earlier live Relay checks used two processes on one computer/network; fresh live Relay, separate-network reliability, four-player sessions and complete live online matches remain unverified for this update. There is no public matchmaking or automatic updater.

For a problem report, include release/source from `BUILD-INFO.json`, operating system, map/faction and reproduction steps in [GitHub Issues](https://github.com/AdamGardelov/howl-for-maul/issues). Do not post passwords or live join codes.
