# Howl for Maul — Friends Playtest 2 — Living Factions

**Build together. Keep the hearth lit.** Living defenders arrive in Howl for Maul: twelve distinct faction themes, 76 recognizable designs, and a centered north-facing camera reset. Play solo offline or build mazes with up to four friends online.

## Download and play

| Your computer | Download | Start |

| Windows x64 | [Windows ZIP](https://github.com/AdamGardelov/howl-for-maul/releases/download/v0.1.0-playtest.2/Howl-for-Maul-v0.1.0-playtest.2-Windows-x64.zip) | Extract the whole ZIP, then open `HowlForMaul.exe`. |
| Linux x64 | [Linux archive](https://github.com/AdamGardelov/howl-for-maul/releases/download/v0.1.0-playtest.2/Howl-for-Maul-v0.1.0-playtest.2-Linux-x64.tar.gz) | Extract, then run `./Start-Howl-for-Maul.sh` from that folder. |

**No Unity installation or Unity account is needed.** Keep all extracted files together. The automatic “Source code” downloads below are for developers; use the Windows or Linux download above to play. Read `START-HERE.txt` inside the archive for controls and troubleshooting.

## Play together

**Everyone should install Playtest 2 into a fresh folder. Do not mix Playtest 1 and Playtest 2 in a match.** Choose **Play → map → Multiplayer → Host online**, then share the generated join code and optional password with your friends. They choose **Join with code**. Complete the lobby, choose factions and starting positions, vote on difficulty, and defend together. Relay connections do not require router port forwarding.

Enter opens team chat. P votes to pause/resume. The host controls game speed. Keep the host's game open: reconnect and host migration are not available yet. Solo works offline and starts at Last Stand with the full team budget.

## New since Playtest 1

- **Twelve clear faction themes:** Ice, Nature, Fire and Storm on Rimewatch; Tech, Beasts, Magic, Air, Earth, Spirits, Dragons and Water on Ironfold.
- **Living defenses:** 64 creature and spirit designs join five tree guardians and seven workshop mechanisms. Updated faction names, portraits, materials, idle and firing motion, projectiles and sound profiles make the orders easier to tell apart.
- **Rootbound trees:** different tree species, seed attacks and Briar Elder's hooked branches and thorn volleys.
- **Within-faction recognition:** stronger individual shapes and weapon silhouettes across all 76 defenders, visible in the chooser and construction previews.
- **Camera reset:** R faces north and centers the map horizontally while keeping your zoom.

Both map layouts, wall-tight freeform mazing, tower prices/stats, team economy, all-active lanes and online protocol are preserved. These are the first complete creature-family models; further anatomy, animation and sound polish is planned.

## Playtest status

This is a **free prerelease for feedback**, not a finished commercial release. Linux packaged runtime/menu checks pass. The source checkpoint passes 73 simulation regressions, 13 focused Unity cases and an automated replay of two historical twenty-wave paid campaigns; this is not a full Unity-suite or human-playtest claim. Windows was cross-built successfully but has **not been run on a native Windows PC here**. Earlier online Relay checks used two Linux processes on one computer/network. Networking is unchanged and was not rerun for this art update; separate-network reliability, four-player live sessions and complete online matches still need testing. The Windows executable is not signed. There is no public matchmaking or automatic updater; install each new release into a fresh folder.

For a problem report, include the release/source from `BUILD-INFO.json`, operating system, map/faction and steps to reproduce. Use [GitHub Issues](https://github.com/AdamGardelov/howl-for-maul/issues). Avoid posting passwords or live join codes.
