# Howl for Maul — Friends Playtest 1

**Build together. Keep the hearth lit.** The first downloadable playtest of Howl for Maul: a cooperative maze-defense game with two maps, distinct factions, and offline solo or online games for up to four players.

## Download and play

| Your computer | Download | Start |

| Windows x64 | [Windows ZIP](https://github.com/AdamGardelov/howl-for-maul/releases/download/v0.1.0-playtest.1/Howl-for-Maul-v0.1.0-playtest.1-Windows-x64.zip) | Extract the whole ZIP, then open `HowlForMaul.exe`. |
| Linux x64 | [Linux archive](https://github.com/AdamGardelov/howl-for-maul/releases/download/v0.1.0-playtest.1/Howl-for-Maul-v0.1.0-playtest.1-Linux-x64.tar.gz) | Extract, then run `./Start-Howl-for-Maul.sh` from that folder. |

**No Unity installation or Unity account is needed.** Keep all extracted files together. The automatic “Source code” downloads below are for developers; use the Windows or Linux download above to play. Read `START-HERE.txt` inside the archive for controls and troubleshooting.

## Play together

Everyone should install this same release. Choose **Play → map → Multiplayer → Host online**, then share the generated join code and optional password with your friends. They choose **Join with code**. Complete the lobby, choose factions and starting positions, vote on difficulty, and defend together. Relay connections do not require router port forwarding.

Enter opens team chat. P votes to pause/resume. The host controls game speed. Keep the host's game open: reconnect and host migration are not available yet. Solo works offline and starts at Last Stand with the full team budget.

## Playtest status

This is a **free prerelease for feedback**, not a finished commercial release. Linux packaged runtime checks pass. Windows was cross-built successfully but has **not been run on a native Windows PC here**. Online Relay has been checked with two Linux processes on one computer/network; separate-network reliability, four-player live sessions and complete online matches still need testing. The Windows executable is not signed. There is no public matchmaking or automatic updater; install each new release into a fresh folder.

For a problem report, include the release/source from `BUILD-INFO.json`, operating system, map/faction and steps to reproduce. Use [GitHub Issues](https://github.com/AdamGardelov/howl-for-maul/issues). Avoid posting passwords or live join codes.
