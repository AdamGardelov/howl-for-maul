# Howl for Maul — Friends Playtest 3 — Smoother Construction

This update fixes a major source of freezing when building during an active wave. It includes all twelve faction themes and 76 defenders from Playtest 2.

**No Unity installation or Unity account is needed.** Keep all extracted files together. Use these desktop downloads rather than GitHub's automatic “Source code” archives. Controls and troubleshooting are in `START-HERE.txt`.

## Play together

**Everyone should install Playtest 3 into a fresh folder and use the same version.** Choose **Play → map → Multiplayer → Host online**, then share the join code and optional password privately. Friends choose **Join with code**. Relay does not require router port forwarding. Choose factions and starts, vote difficulty, and defend together.

Enter opens team chat; P votes to pause/resume; the host controls speed. Keep the host's game open: reconnect and host migration are not available. Solo works offline and starts at Last Stand with the full team budget.

## Fixed since Playtest 2

- **Construction stalls:** navigation now reuses collision geometry and updates it near the edited tower instead of repeatedly scanning every tower across the whole map for each destination.
- **Less allocation during combat:** route buffers and heap storage are reused; warmed enemy route lookups no longer create temporary string keys.
- Building, selling and destroyed towers retain exact collision clearance, breach costs and deterministic route behavior. Maps, prices, faction stats, art and the network protocol are unchanged.

In the 160-tower routing stress test, median work per edit fell from **1,856.64 ms to 17.41 ms on Ironfold** and **1,240.56 ms to 12.49 ms on Rimewatch**. These are CPU routing samples on the development machine, **not an FPS guarantee** or a claim that every possible stutter is eliminated.

## Verification and playtest limits

75 simulation regressions and 77 targeted Unity checks pass, including paid construction during actual waves and exact replays of two historical twenty-wave paid campaigns. Local two-process multiplayer checks pass on both maps. Linux packaged runtime and menu checks pass. Full evidence is in [construction verification](https://github.com/AdamGardelov/howl-for-maul/blob/61996b05a402ab8f2800d678a554a665626f0252/Docs/Verification/Construction-Hitches/README.md).

This remains a **free prerelease**. Windows cross-build succeeds, but native Windows execution is unverified here and the executable is unsigned. Earlier live Relay checks used two Linux processes on one computer/network; fresh live Relay, separate-network reliability, four-player live sessions, complete online matches and target-GPU performance remain unverified for this update. There is no public matchmaking or automatic updater. Earlier playtest releases remain available unchanged.

For a problem report, include release/source from `BUILD-INFO.json`, operating system, map/faction and reproduction steps in [GitHub Issues](https://github.com/AdamGardelov/howl-for-maul/issues). Do not post passwords or live join codes.
