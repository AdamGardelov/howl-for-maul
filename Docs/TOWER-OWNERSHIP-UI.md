# Tower ownership and sale readout

The selected-tower inspector now names its owner. When inspecting another local player's tower, it tells the player which slot to switch to and disables upgrade/sell controls. Upgrade is also disabled when the current wallet cannot afford it or the match has finished; an affordability message gives the shortfall. Deselect remains available.

The sell button shows the exact refund from the existing paid-investment ledger, including upgrades and faction-specific base refunds. Free-build mode calls it Remove tower. Read-only World queries return no owner/refund for a tower that has been sold or destroyed, even when an internal historical record remains. Simulation ownership checks, refund rules and wallet debits are unchanged.
